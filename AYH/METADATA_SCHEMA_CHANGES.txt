1. MODELS (careapp/models.py)
--------------------------------------------------------------------------------

BLOOD REQUEST (BloodRequest) - Extended:
  - request_id: UUIDField (unique, indexed, default uuid4) - global unique id
  - city, state: CharField (optional)
  - hospital_id: CharField (optional, indexed)
  - patient_age: PositiveIntegerField (optional)
  - units_required: PositiveIntegerField (optional, synced from units_needed)
  - urgency_level: CharField (optional, derived from urgency)
  - source: CharField - App / Call / Hospital (default 'app')
  - status: CharField - Open / Fulfilled / Failed / Cancelled (default 'open')
  - closed_at: DateTimeField (optional)
  - closure_reason: CharField - Success / Timeout / Cancelled (optional)
  - closure_type: CharField - Donor / BloodBank / Mixed (optional)
  - sla_minutes: PositiveIntegerField (optional)
  - save() override: auto-fills urgency_level and units_required from urgency/units_needed

NEW MODELS ADDED:
  - RequestTimeline: timeline_id (UUID PK), request_id (FK), event_type (CREATED, SEARCH_STARTED, DONOR_ACCEPTED, STANDBY_ACTIVATED, BANK_TRIGGERED, FULFILLED), event_time, actor (SYSTEM/ADMIN/DONOR/BANK), metadata (JSON)
  - EtaTracking: eta_id (UUID PK), request_id (FK), source (Donor/BloodBank), committed_at, committed_eta_min, actual_arrival_at, actual_duration_min, eta_breached, breach_minutes
  - DelayReason: delay_id (UUID PK), request_id (FK), stage (Search/Acceptance/Transit), delay_reason, delay_category (Supply/Distance/Ops), delay_minutes, identified_at, resolved_at, resolved
  - DonorMaster: donor_id (UUID PK), user (OneToOne optional), blood_group, city, latitude, longitude, last_donation_date, availability_status (Available/Busy), reliability_score
  - DonorAssignment: assignment_id (UUID PK), request_id (FK), donor (User FK), donor_master (FK), donor_type (Primary/Standby), assigned_at, accepted_at, dropped_at, drop_reason, eta_minutes, distance_km, status (Accepted/Dropped/Completed)
  - DonorMovement: movement_id (UUID PK), assignment_id (FK), location_lat, location_long, recorded_at, distance_remaining_km, eta_remaining_min
  - FallbackAction: fallback_id (UUID PK), request_id (FK), fallback_type (Radius/Standby/Bank/NGO), trigger_reason, trigger_stage, trigger_level, triggered_at, resolved_at, success
  - RadiusExpansionLog: radius_id (UUID PK), request_id (FK), old_radius_km, new_radius_km, expanded_at, success
  - StandbyAction: standby_id (UUID PK), request_id (FK), donor (User FK), donor_master (FK), activated_at, used, cancelled_at
  - BloodBankMaster: blood_bank_id (PK), name, city, latitude, longitude, reliability_score
  - BloodBankFallback: bank_fallback_id (UUID PK), request_id (FK), blood_bank_id (FK), units_requested, units_confirmed, contacted_at, confirmed_at, eta_minutes, success
  - HospitalMaster: hospital_id (PK), hospital_name, city, tier
  - HospitalMetrics: hospital_id (FK), date, total_requests, fulfilled, failed, avg_fulfillment_time, sla_breach_pct (unique_together hospital, date)
  - DimDate: date (PK), day, month, quarter, year
  - DimCity: city, state, region (unique_together city, state)

--------------------------------------------------------------------------------
